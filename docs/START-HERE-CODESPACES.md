# Começar no GitHub Codespaces

1. Abra o repositório na branch `studio/advogado`.
2. Use o link direto: https://codespaces.new/henriquefelix8920/advogado/tree/studio/advogado?quickstart=1
3. Aguarde o Dev Container preparar o ambiente.
4. Entre no GitHub Copilot no VS Code Web.
5. Abra Chat e escolha **Diretor WEB STUDIO**.
6. Adicione o briefing em `docs/briefing/` ou anexe ao Chat.

Se o Copilot não aparecer, confira autenticação, extensão, harness Copilot e recarregue a janela. Os agentes estão em `.github/agents/` e as skills em `.github/skills/`.

Codespaces é uma máquina remota vinculada à conta GitHub. Confira cotas/custos e pare a máquina quando terminar.
