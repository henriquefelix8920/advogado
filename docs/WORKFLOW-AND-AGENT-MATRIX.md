# Workflow e matriz de agentes

| Fase | Responsável | Colaboração | Saída |
|---|---|---|---|
| Briefing/discovery | Diretor + Estrategista | Copywriter | Fatos, hipóteses e lacunas |
| Estratégia | Estrategista | Diretor | Posicionamento e conversão |
| Conceito visual | Diretor de Arte & UX | Motion | Sistema visual e layout |
| Copy | Copywriter | Estrategista | Conteúdo e microcopy |
| Arquitetura | Arquiteto Web | Desenvolvedor | Decisão e mapa técnico |
| Motion | Diretor de Motion | Arte + Dev | Storyboard |
| Build | Desenvolvedor | Especialistas | Implementação |
| Auditoria | Auditor QA | Diretor | Achados priorizados |
| Correção | Desenvolvedor | Auditor reavalia | QA concluído |
| Release | Steward GitHub | Diretor | Branch/PR autorizado |

Discovery visual, estratégia e pesquisa técnica podem ocorrer em paralelo. Copy e wireframe iteram sincronizados. Desenvolvimento começa após decisões essenciais. Nunca delegue edição simultânea do mesmo arquivo. Auditoria referencia uma versão identificada. Release depende da autorização de publicação.
