# Rafael Andrade — Advocacia Criminal

Site institucional em versão de revisão, desenvolvido a partir do briefing recebido em 27/11/2026.

## Rodar localmente
É um site estático, sem dependências de runtime. Abra `index.html` no navegador ou sirva a pasta com qualquer servidor HTTP estático.

Exemplo:
```bash
python3 -m http.server 8080
```

## Estrutura
- `index.html`: conteúdo institucional, áreas, artigos, FAQ, contato e privacidade.
- `styles.css`: identidade visual e responsividade.
- `app.js`: navegação mobile, movimento progressivo e validação/cópia local do formulário.
- `docs/ENTREGA-WEB-STUDIO.md`: decisões, pendências, QA e limites da entrega.

## Importante antes de publicar
O projeto usa nome de demonstração e dados profissionais não confirmados. A faixa de revisão permanece visível de propósito. Não publicar antes de validar nome, inscrição OAB, contatos, endereço, biografia, fotografia, qualificações, plantão 24h e textos jurídicos. O formulário não envia dados a um servidor: apenas valida e tenta copiar a mensagem no dispositivo. Integração de envio depende de canal confirmado e decisão de privacidade/segurança.
